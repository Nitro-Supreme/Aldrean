## How to Use Audio Files

When you add MP3 files for audio narration:

1. Create an `assets/audio/` directory
2. Place your MP3 file there (e.g., `chapter-01.mp3`)
3. Update the front matter above:
   - Change `audio_file: null` to `audio_file: /assets/audio/chapter-01.mp3`
   - Change `audio_duration: null` to `audio_duration: "XX minutes XX seconds"`

The audio player will then appear at the top of the chapter for readers to enjoy.

## Formatting Tips

- Use `##` for section headers within chapters
- Use `**text**` for bold emphasis
- Use `*text*` for italics
- Start new scenes with a blank line and visual break if desired
